# omageeko branding

One mark everywhere: Omarchy's logo with its inner square turned into a G (omageeko on top of Omarchy). Source: `packages/omageeko/overlay/share/branding/omageeko-icon.txt` (54×26 block grid, Omarchy's logo dimensions).

| Where | How |
|---|---|
| fastfetch, About | installed as skel `~/.config/omarchy/branding/about.txt`; fastfetch colours it green |
| bar menu button, Update › Omageeko | `omageeko.ttf`, glyph U+E900, generated by `packages/omageeko/make-icon-font.py` at build time |
| `omarchy` app icon (`/usr/share/omarchy/icon.png`, `pixmaps/omarchy.png`, hicolor 256) | the same grid rendered at build time, openSUSE green `#73ba25` on transparent |
| screensaver | the OMAGEEKO wordmark in Omarchy's block font (`overlay/share/branding/logo.txt`) |

Not replaced: Omarchy's Plymouth and SDDM logos (omageeko uses Tumbleweed's `bgrt` boot splash and lightdm) and `logo.svg` (unused at runtime).

To change the mark, edit the grid and rebuild: font, icon and fastfetch logo all follow. `candidates/` keeps the explored designs (Geeko, Tumbleweed hourglass, OG wordmark) and the scripts that drew them.
